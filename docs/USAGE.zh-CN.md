# AiSteve — 使用说明

[English](../README.md) · [简体中文](../README.zh-CN.md) · [构建指南](BUILD.zh-CN.md) · [现状与不足](STATUS.md) · **使用说明**

> 所有指令以 **`/as`** 开头。**没有指令面板**，全部通过聊天框交互。
> **同时只能存在 1 个 AI 玩家**。它能理解自然语言、像真人一样行动
> （挖矿、砍树、合成、钓鱼、种田、翻箱子、建造、探索）。
>
> 想先知道**哪些能做、哪些还做不到**，请看 [STATUS.md](STATUS.md)。

---

## 0. 安装前提（必读）

- 本模组是 **Minecraft 1.20.1 + Forge** 模组，**不能用于 Fabric**。
- 装进 `mods\` 的必须是 **`aisteve-1.0.0-all.jar`**（带依赖的版本）。
- 配置在 `config\aisteve-common.toml`（**不是 mods**），改完需**重启游戏**。

| 文件 | 放哪里 |
| --- | --- |
| `aisteve-1.0.0-all.jar` | ✅ `mods\` |
| `aisteve-common.toml` | ✅ `config\`（不要放 mods！） |

---

## 1. 快速开始

```text
# 1) 创建 AI 玩家（同时只能有一个）
/as create Bob

# 2) 直接对它说话（这就是主要用法）
/as 帮我弄一个羊排
/as 去挖点铁
/as 在我前面建个房子

# 3) 给它东西 / 它给你的东西收回来
/as give              ← 把你手上拿的物品交给它
/as take              ← 让它把身上的东西都交给你
```

> `/as give` 是核心交互：**你手上拿着什么就给它什么**。

---

## 2. 全部指令

| 指令 | 作用 |
| --- | --- |
| `/as create <名字>` | 创建 AI 玩家（已存在时会提示先 remove） |
| `/as remove` | 移除 AI 玩家（它会把手上的东西掉在地上） |
| `/as info` | 查看状态：位置、生命、**背包内容**、当前目标 |
| `/as stop` | 立即停止当前任务 |
| `/as cleanup` | **强制清除世界上所有 AI 实体**（含旧版本遗留的"幽灵"）。升级模组后若出现两个 AI，用它 |
| `/as come` | 把 AI 叫到你身边（万一它走丢/卡住了） |
| `/as say <内容>` | 对 AI 说话（下达任务或闲聊） |
| `/as <内容>` | 同上，`say` 可省略 |
| `/as give` | 把手上的物品交给 AI |
| `/as give <物品> [数量]` | 直接给指定物品（便于测试） |
| `/as take` | 让 AI 把身上所有东西交给你 |

## 3. 它能"听懂"什么

AI 由大模型驱动，**不需要背固定指令**，用日常说法即可。它会自己判断该怎么做。

### 3.1 会区分「任务」和「闲聊」

| 你说 | 它怎么反应 |
| --- | --- |
| `你好呀` / `你会干什么？` | **只是聊天**，用中文自然回你，不会乱跑 |
| `帮我弄一个羊排` | **当成任务**，拆解成步骤去执行 |

### 3.2 任务拆解示例（羊排场景）

你说：`/as 帮我弄一个羊排`，并且**先给了它一个打火石**：

```text
/as create Bob
/as give            ← 手上拿着打火石，交给 Bob
/as 帮我弄一个羊排
```

AI 会自己推理出这个链条：

1. `use_item` 用打火石点燃附近一只羊
2. `attack` 杀掉那只着火的羊（**着火的动物掉落熟肉**）
3. `pickup` 捡起熟羊排
4. `give` 走回你身边把羊排交给你

**如果你没给它打火石**，它会说：
> `<Bob> 我需要一个打火石才能烤羊排，能给我一个吗？`

然后等你给 —— 这就是"理解 + 会求助"，而不是假装完成。

### 3.3 其他常用说法

```text
去挖点铁 / 挖20个钻石
砍点木头
在我前面建个房子 / 建个城堡
跟着我
把僵尸清一下 / 打那只苦力怕
把你身上的东西给我
去那边捡一下掉落物
```

## 4. 跟随之类"驯服的狼"行为

- **任务没完成时**：AI 会**一直待在你附近**（约 6 格以内就停，超过就小跑跟上来）——不会走丢。
  它在执行具体步骤时会暂时离开，但**步骤之间会自动回到你身边**。
- **任务完成后**：停止跟随，进入空闲状态。
- 想让它彻底停下：`/as stop`

## 5. 它的能力清单（AI 可用的动作）

AI 内部使用这些"基础动作"完成任务，你可以据此判断它能做什么：

| 动作 | 说明 |
| --- | --- |
| `pathfind` | 走到指定坐标 |
| `loot_container` | **打开附近箱子/木桶/熔炉取物**（像真人翻箱子；村庄里能找到食物） |
| `explore` | **朝一个方向探索一段路**（附近没东西时主动去找，而不是原地放弃） |
| `mine` | 采集方块（**会自动走到最近的这种方块旁挖掉并收进背包**；砍树会砍下整棵树；**矿石会自动下矿挖到对应深度**；**只挖看得见的方块**——埋在土里的会先把上面那层挖开，不会隔着方块挖） |
| `place` | 放置方块 |
| `use_item` | **对任意实体/方块/自己使用任意物品**（点燃、吃东西、放置等） |
| `attack` | 攻击/猎杀指定生物，可指定数量 |
| `pickup` | 捡起附近掉落物 |
| `give` | 把物品交给玩家 |
| `craft` | **合成物品**（真查配方、扣材料；需要工作台时会自己造一个） |
| `fish` | **钓鱼**（水边，需背包有鱼竿） |
| `farm` | **收割作物**（小麦/胡萝卜/马铃薯/甜菜根，自动补种） |
| `gather` | 自动采集（木头/矿石/肉类） |
| `build` | 建造结构（house / castle / tower / barn / modern …） |
| `follow` | 跟随玩家 |
| `say` | 在聊天框说话（索要物品、说明情况） |

> 关键设计：这些是**通用基础动作**，不是为某个场景写死的。
> AI 通过组合它们来完成任意任务，所以你能想到的合理要求基本都能做。

### 5.1 它是怎么"找东西"的（像真人一样）

任务需要某样东西时，AI 会按这个顺序想办法，而不是原地卡住：

| 顺序 | 做法 | 例子 |
| --- | --- | --- |
| 1 | **用现成的** | 附近有箱子/木桶 → `loot_container` 翻箱子拿食物 |
| 2 | **利用村庄** | 识别到 bell / composter / hay_block → 知道是村庄，去翻箱子、找农田 |
| 3 | **可再生食物** | 附近有水 → `fish` 钓鱼；有农田 → `farm` 收割 |
| 4 | **去打猎/采集** | 附近真有动物或树 → `attack` / `mine` |
| 5 | **自己做** | 缺工具/材料 → `craft`（会自己造工作台） |
| 6 | **主动探索** | 附近什么都没有 → `explore` 朝一个方向走几十格，**移动后再判断** |
| 7 | **求助** | 真找不到才 `say` 让你帮忙，并说明原因 |

### 5.2 它能自己"创业"了

现在这些链条可以自动跑通（不需要你给现成工具）：

```text
/as 去弄点木头，然后做个镐子
```
→ `mine oak_log`（砍树）→ `craft oak_planks`（木板）→
`craft crafting_table`（工作台）→ `craft wooden_pickaxe`（木镐）

```text
/as 去挖点钻石
```
→ 地表找不到 → **自动挖楼梯下到 Y=-59** → 分支挖矿 → 挖到钻石回背包

```text
/as 找点吃的
```
→ 翻箱子 / 钓鱼 / 收割农田 / 打猎 / 探索，按环境择优

### 5.3 它会记住去过的地方

发现村庄、水源、农田、森林后会**记下来**，并且**重启游戏依然记得**。

你可以这样利用它：

```text
/as 去之前那个村庄拿点吃的
```
（提示词里会告诉它"我记得的地点：village at [x,y,z] (95m away)"）

## 6. 背包：怎么给它东西 / 怎么拿回来

```text
# 看它有什么（推荐）
# 手上空着 → 右键点一下 AI，直接打开它的背包窗口

# 给（推荐做法）
# 手上拿着打火石 → 右键点 AI（每点一次给 1 个）
# 手上拿着打火石 → /as give

# 给指定物品（数量可选）
/as give flint_and_steel
/as give cooked_mutton 5

# 看它有什么（文字版，适合服务器日志/远程）
/as info

# 全部拿回来
/as take
```

**背包窗口是只读的**：槽位不能拖、不能取，Shift 点击也不搬运。原因是它的背包正是它
自己干活时依据的状态（合成会提前一步算出要扣哪些材料），中途被抽走东西会让它的计划对不上。
要拿回东西用 `/as take`（一次全取），要给它东西就右键或 `/as give`。
走开 8 格、或者它不在了，窗口会自动关闭。

物品 ID 用原版名即可（`flint_and_steel`、`oak_log`、`cooked_mutton` …），
也支持中文别名：`打火石`、`羊排`、`牛肉`、`猪肉`、`鸡肉`。

## 7. 排错

| 现象 | 原因 / 处理 |
| --- | --- |
| `/as` 指令不存在 | 用的是旧的 `-all.jar` 或模组没加载；确认日志里 `Loading Minecraft 1.20.1 with Forge` |
| `/as create` 说已存在 | 同时只能有一个 AI。先 `/as remove` |
| 说了话没反应 | 查 `logs/latest.log` 搜 `deepseek`。见下两行 |
| **每句话都回"没处理成功/没理解"** | 用旧 jar 会有此问题（构造函数漏初始化背包→解析前抛异常）。换最新 jar 即可；若仍出现，看日志里有没有 `NullPointerException` |
| 它"消失"了 | 已修复（旧版会被原版按"远处静止生物"自动清除）。若仍丢失：`/as come` 叫回来，或 `/as remove` 后 `/as create` 重建 |
| **出现两个 AI，只有新的听话** | 旧版本创建的实体残留。执行 `/as cleanup` 全部清除，再 `/as create <名字>`。（新版本已能自动接管并清理，此指令是兜底） |
| 它说"附近没有 X" | 新版会先 `explore` 去找。若仍找不到，说明附近确实没有，带它过去或给它即可 |
| 它说"我缺 X 材料" | 正常——它在报告 `craft` 缺什么。给它材料，或让它先去采集 |
| 挖矿很久没结果 | 钻石等稀有矿本来就看运气。日志会显示 `reached Y=-59 - starting branch mining`，说明它确实在下挖 |
| 日志 `No API key configured` | 没配 key。改 `config\aisteve-common.toml` 的 `[deepseek].apiKey` 并**重启** |
| 日志 `Plan received: (N tasks, 0ms, 0 tokens)` | 0ms/0tokens = **不是真实模型回复**，是降级。多半是 key/网络问题 |
| 它说"我没有 XXX" | 正常，它在向你索要。用 `/as give` 给它 |
| 它说"**这个我暂时做不了：…**" | 它试过几种方法都不行，**已停止**并在说明原因。按提示给它缺的东西，或换个更具体的指令 |
| 它说"**只挖到 3/8**"这类 | 正常汇报**部分完成**（附近就这么多）。不是故障，也不会再反复重试 |
| 它没跟上你 | 任务完成后就不再跟随；`/as stop` 可强制停止 |
| 建造不完整 | 已修复（旧版只建 1/4）。确保用最新 jar |
| 面板/按 K 没反应 | **K 面板已被移除**，改用 `/as` 指令 |

> 改完 config **必须重启游戏**；游戏自动生成的那份 config 里 key 是空的。

## 8. 已知限制

- **合成只支持工作台配方**：能合成绝大多数物品（含自动造工作台），但不支持熔炉冶炼、
  酿造、铁砧等特殊配方。
- **只用手上的材料**：它不会凭空变出物品。缺材料时会先 `craft`，
  再不行会 `explore`/`mine` 去采集，最后才向你索要。
- **挖矿是"找矿"不是"刷矿"**：会下到正确深度做分支挖矿，但不保证一定挖到
  （钻石本来就稀有）。挖不到会如实告诉你，而不是假装成功。
- **挖矿"看得见才挖得到"**：它不会隔着方块取物。埋着的矿会先把覆盖的土/石挖开
  （这些不算产出），挖不到又走不过去时会如实说"附近没有能挖到的 X"。
  另外它挖方块是**瞬间完成**的（没有原版的挖掘耗时），这是刻意的简化。
- **钓鱼需要鱼竿**：没有鱼竿会明确提示你给它。钓鱼过程做了原版概率模拟，
  但不是逐帧还原原版浮标物理。
- **探索是"走一趟"**：`explore` 朝一个方向走几十格就停下，不是无限漫游。
- **记忆只记"地点"**：会记住村庄/水源/农田/森林的位置（跨会话保留），
  但不会记住"某个箱子里有什么"这类细节。
- **动作是串行的**：同一时间只做一件事。
- **对话上下文不持久**：重启后聊天记忆重置（**背包与世界记忆会保留**）。
- **依赖模型能力**：规划质量取决于所选 DeepSeek 模型。
- 攻击**永远不会**以玩家或自己为目标。
